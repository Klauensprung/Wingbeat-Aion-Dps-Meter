Ground-loot protocol research
-----------------------------
The 0x2336 load-complete coordinate layout and the 0x2136 coordinate offsets
also support the last-captured-position marker, researched from:
https://github.com/SkeeveAN/Aion-DPS-Meter/blob/a0e8897414278b82f3005e1e93b524810c07c019/docs/protocol/sitzungs-frames.md
Explicit zone-to-terrain mappings use factual associations from Protocol/Aion2Maps.cs
at the same revision. No continuous position updates or inferred movement are
claimed. Marker age is displayed; unknown terrain mappings remain unavailable.
The local-zone ID offset in 0x2136 was researched from:
https://github.com/SkeeveAN/Aion-DPS-Meter/blob/a0e8897414278b82f3005e1e93b524810c07c019/docs/protocol/position-frames.md
Map ID, finite XYZ coordinates and opaque remainder length are retained.
The same position notes and Aion2FrameDecoder.cs at the pinned revision document
the final three f32 coordinates in effect apply/refresh frames as the caster's
position. Wingbeat retains plausible finite coordinates separately from the
target and uses them only for the identified local caster, on an already known
map, without rewinding newer observations. This improves action-based updates;
the reference explicitly reports no continuous self-position stream during
ordinary walking/flying. Regional live validation remains outstanding.
Transition kind is not interpreted. Synthetic tests do not verify regional wire
compatibility. The map ID is attached to subsequent attributed loot events.
Fixed record sizes, offsets and disappearance flags were researched from:
https://github.com/SkeeveAN/Aion-DPS-Meter/blob/a0e8897414278b82f3005e1e93b524810c07c019/docs/protocol/inventar-quest-frames.md
The notes distinguish pickup flag 1 from disappearance flag 0 and document
multi-entry packets. GroundLootWire independently implements bounded readers
for these factual layouts; no source implementation or captured player records
are bundled. Synthetic fixtures check framing and field extraction, not live
regional compatibility or completed local-player pickup attribution.
Source repository: Copyright (c) 2026 SkeeveTV, MIT; see licenses/SkeeveTV-MIT.txt.

Health/stat and effect protocol follow-up (experimental)
The same pinned Aion2FrameDecoder.cs and combat-frames.md document health/stat
format flags with type/u32 prefixes and counted type/u64 fields. HealthWire
independently implements exact-length reading, emitting only explicit kind-0
current HP. Other stat kinds are ignored, including ambiguous kind 7; no maximum
HP is inferred. The existing compact single-u32 current-HP form remains accepted.
Ordinary form-17 effect headers now use the shared effect layout instead of being
assumed to be enrage; only the previously recognized ID/duration pair emits the
boss-enrage signal. These changes follow a live aggregate baseline that observed
rejected health/stat and form-17 records. Synthetic checks validate the added
layouts; those counts alone do not establish live semantic equivalence.

Zone-state protocol (experimental)
The factual 0x0140 short/extended record layouts were researched from:
https://github.com/SkeeveAN/Aion-DPS-Meter/blob/a0e8897414278b82f3005e1e93b524810c07c019/docs/protocol/sitzungs-frames.md
ZoneStateWire independently reads exact-size fields for zone, raw phase,
timestamp, variant and opaque reference. The source labels the interpretation
of phase 3 as an ended dungeon run a hypothesis. Wingbeat therefore preserves
observations without asserting clears or ending combat. Repeated phases retain
their first observation and history is bounded. Synthetic checks verify framing
and retention, not regional compatibility or dungeon completion semantics.
